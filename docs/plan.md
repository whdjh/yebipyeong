# 예비평 서비스 요구사항

## 1. 서비스 개요

### 서비스명
예비평

### Repository
`yebipyeong`

### 목적
예비군이 실제로 경험한 훈련장 운영 방식을 익명으로 공유하고,
다른 예비군이 자신이 배정받은 훈련장의 운영 특성을 미리 확인할 수 있도록 한다.

일반적인 자유 후기 커뮤니티보다는
정해진 질문에 답하면서 데이터가 누적되는 평가 서비스에 가깝게 구성한다.

---

## 2. 핵심 원칙

- 로그인 없이 사용할 수 있다.
- 평가 작성자는 익명이다.
- 사용자 계정, 닉네임 등을 받지 않는다.
- 애플리케이션 DB에 작성자의 IP를 저장하지 않는다.
- 기기 식별 정보 등을 이용한 사용자 추적을 하지 않는다.
- 중복 평가에 대한 별도의 제한을 두지 않는다.
- 자유서술형 후기는 제공하지 않는다.
- 모든 평가는 미리 정의된 객관식 질문으로만 진행한다.
- 특정 대대장, 간부, 조교 등 개인을 평가하는 서비스로 만들지 않는다.
- 특정 개인의 이름을 입력하는 기능을 제공하지 않는다.
- 훈련장 내부 시설 위치나 군사적으로 민감한 정보를 수집하는 기능을 제공하지 않는다.

---

## 3. 훈련장 검색

사용자는 자신이 훈련받은 정확한 훈련장 명칭을 모를 수 있다.

국방부 또는 병무청에서 받은 알림톡이나 소집통지서에는 다음과 같이 주소 형태로 안내될 수 있다.

예:

`경기도 이천시 진상미로 1700-29`

따라서 훈련장은 현재 위치나 GPS를 이용해서 찾는 것이 아니라
사용자가 안내받은 정보를 직접 입력해서 찾도록 한다.

### 검색 입력

질문:

> 어디에서 훈련받으셨나요?

Placeholder:

> 안내받은 훈련장명 또는 주소를 입력해주세요.

보조 문구:

> 알림톡이나 소집통지서에 적힌 내용을 그대로 입력해도 돼요.

사용자는 다음 방식으로 검색할 수 있다.

- 훈련장명
- 전체 주소
- 도로명 주소 일부

서로 다른 이름으로 불리는 동일한 훈련장은 하나의 훈련장으로 관리한다.

예:

`OO동원훈련장`

`OO예비군훈련장`

`경기도 이천시 OO로 123`

위 값들이 동일한 장소라면 하나의 `TrainingCenter`로 매칭한다.

평가에는 사용자가 검색창에 입력한 문자열 자체가 아니라
매칭된 훈련장의 ID를 사용한다.

### 훈련장 목록 정보

목록에는 훈련장명, 주소, 평가 건수, 추천 및 비추천 수를 표시한다.
추천과 비추천 수를 나란히 보여 비율을 확인할 수 있게 한다.

작성자를 식별하지 않고 중복 평가를 제한하지 않으므로,
작성자 수가 아닌 평가 건수로 표시한다.

## 4. 평가 작성 플로우

평가 작성은 두 단계로 구성한다.

### STEP 1. 훈련 기본 정보

한 화면에서 다음 세 가지를 모두 입력한다.

#### 훈련장

훈련장명 또는 안내받은 주소로 검색한다.

#### 훈련 종류

다음 세 가지 중 하나를 선택한다.

- 동원훈련
- 동미참훈련
- 작계훈련

훈련 종류에 따라 STEP 2의 질문이 달라진다.

#### 훈련 시기

연도와 월까지만 입력한다.

예:

`2026년 9월`

정확한 훈련 일자는 받지 않는다.

훈련장의 운영 방식은 시기에 따라 달라질 수 있으므로
평가 데이터에는 훈련받은 연도와 월을 포함한다.

---

## 5. STEP 2. 훈련 평가

선택한 훈련 종류에 해당하는 모든 질문을 한 화면에 표시한다.

질문은 모두 객관식이다.

모든 필수 질문에 답하기 전까지 완료 버튼은 disabled 상태다.

모든 질문에 답하면 완료 버튼이 활성화된다.

## 6.6 훈련 진행 정도

### 질문

> 훈련은 어떻게 진행됐나요?

### 선택지

- 계획보다 과하게 진행됐어요.
- 계획대로 진행됐어요.
- 일부 축소해서 진행됐어요.

※ 해당 문구는 추후 서비스 공개 전 표현을 한 번 더 검토한다.
특정 부대가 규정을 위반했다는 의미가 아니라
사용자가 경험한 훈련 진행 정도를 표현하는 항목이다.

# 9. 평가 제출 조건

평가 페이지에 진입했을 때 완료 버튼은 기본적으로 비활성화한다.

다음 조건을 모두 만족하면 완료 버튼을 활성화한다.

- 훈련장이 선택되어 있음
- 훈련 종류가 선택되어 있음
- 훈련 연도가 선택되어 있음
- 훈련 월이 선택되어 있음
- 해당 훈련 종류의 모든 질문에 답변함

자유서술형 입력은 존재하지 않는다.

`잘 기억나지 않아요`와 같은 선택지도 제공하지 않는다.

# 10. 익명성 및 데이터 수집

서비스 이용을 위해 회원가입이나 로그인을 요구하지 않는다.

평가 데이터에는 작성자를 식별하기 위한 정보를 포함하지 않는다.

저장 대상은 기본적으로 다음과 같다.

- 훈련장
- 훈련 종류
- 훈련 연도
- 훈련 월
- 객관식 질문의 답변
- 추천 여부
- 평가 생성 시각

다음 정보는 애플리케이션 데이터베이스에 저장하지 않는다.

- 이름
- 닉네임
- 이메일
- 전화번호
- 사용자 ID
- IP
- 기기 ID
- 브라우저 fingerprint

사용자별 중복 평가를 감지하거나 제한하기 위한 별도의 추적 기능도 구현하지 않는다.
